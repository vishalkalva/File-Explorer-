📂 Mini File Explorer

A Python console-based application that allows users to perform basic file and folder operations on their computer. This project demonstrates Object-Oriented Programming (OOP), file system navigation, and the use of Python's built-in `os` module.

---

🚀 Features

- 📁 Display Current Directory
- 📂 List Files and Folders
- 📍 Change Directory
- ➕ Create Folder
- ❌ Delete Folder
- 📄 Create File
- 🗑️ Delete File
- 📋 Menu-Driven Interface

---

🛠️ Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- `os` Module
- Functions
- Loops
- Conditional Statements

---

📚 Concepts Practiced

- Object-Oriented Programming
- Classes and Objects
- Constructors (`__init__`)
- File and Folder Management
- Directory Navigation
- Python `os` Module
- User Input Handling
- Menu-Driven Programming

---

▶️ How to Run

1. Clone the repository.
2. Open the project folder.
3. Run the Python file:

```bash
python main.py
```

4. Choose an option from the menu to perform file and folder operations.
